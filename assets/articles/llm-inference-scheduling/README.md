# LLM inference scheduling figures

These seven files are the publication copies of the images referenced by the author's Obsidian article, “LLM 推理调度：如何兼顾吞吐量与响应延迟”. The Obsidian note uses its own adjacent `assets/llm-inference-scheduling/` folder; published HTML uses this directory. Neither copy depends on the ignored `output/` review workspace.

- `inference-metrics-excalidraw-20260926.svg`: author's inference-metrics timeline.
- `fixed-batch.svg`: author's fixed-batch scheduling example.
- `orca_iteration.svg`: author's iteration-level scheduling example.
- `orca-fig4.png`: Yu et al., *Orca*, OSDI 2022, Figure 4.
- `sarathi-serve-fig7.png`: Agrawal et al., *Sarathi-Serve*, OSDI 2024, Figure 7.
- `sarathi-2023-fig4.png`: Agrawal et al., *SARATHI*, arXiv:2308.16369v1, 2023, Figure 4.
- `sarathi-serve-fig9.png`: Agrawal et al., *Sarathi-Serve*, OSDI 2024, Figure 9.

Attribution and links to the papers are preserved in the article's captions and references. Figure bytes are unchanged from the author-provided source files.
